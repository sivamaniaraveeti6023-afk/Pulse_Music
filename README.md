# 🎵 Pulse Music App

A modern and responsive music player built using **HTML, CSS, and JavaScript**. Pulse Music provides a simple and interactive interface for playing songs and controlling playback.

## ✨ Features

* ▶️ Play & Pause music
* ⏮️ Previous & Next song controls
* 🎵 Display song title and artist
* ⏱️ Show song duration
* 📊 Interactive progress bar
* 📱 Responsive user interface
* 🎨 Clean and modern design

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Music controls and functionality
